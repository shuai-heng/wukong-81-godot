# 唐僧 R4 视觉动作审计

## 为什么不能继续直接播放 V6.1 通用映射

V6.1 的 36 Pose 本身是素材库，不等于每一张都适合当前唐僧战斗职业。项目负责人当前硬规则是：唐僧普通攻击必须是远程咒语弹幕，人物动作负责“施法”，VFX/projectile 负责“攻击”，不能再挥锡杖贴脸。

对素材逐张复核后，通用映射存在以下冲突：

- `run` 把 `POSE_06` 混入普通走位；该图是整个人横向腾空，连续播放时像突然侧着飞出去。
- `atk_combo` 使用 `POSE_14/15/16/18`；这些是明显的锡杖横扫、突刺、挥击动作，与远程法师身份证冲突。
- `core_1/core_2/unlock_1` 大量使用 `POSE_19–29`；其中包含完整经文墙、巨大光轮、莲花、锁链等烘焙 VFX。若人物贴图本身播放这些效果，再叠 Godot projectile/impact，就会形成“双技能/贴图感/串视觉”。
- `form/finisher` 包含 `POSE_35` 巨大莲花；当前规范禁止用一张巨大完整插画直接替代法相形成过程。

因此 R4 不删除 V6.1 原始数据，不影响其他英雄；只在唐僧运行时重映射“同一个 kf_t 时刻显示哪张人物 Pose”。

## 锚点

R4 的 `palm` 不再沿用被淘汰 Pose 的 V6.1 锚点。每张允许 Pose 都有对应归一化掌心/袖手释放位置：

- `POSE_02`：合掌中心；
- `POSE_03`：右侧前伸袖口；
- `POSE_13`：右侧袖手；
- `POSE_31/36`：法相/悬空姿势的胸前施法中心。

运行时由当前 `Sprite2D` 的 scale / rotation / flip_h 变换到世界坐标。左右翻转时 palm 同步镜像；projectile 脱手后不再跟人物移动。

## 视觉验收红线

1. 普通走位任何暂停帧都不能出现横飞 `POSE_06`。
2. 普攻任何暂停帧都不能出现 `POSE_14–18` 的挥杖攻击。
3. 普攻/Q/E/G 人物贴图里不能自带完整 projectile、经文墙、巨型莲花或巨型盾。
4. 隐藏 VFX 后，人物仍然像“合掌/前送/护持/诵经”，而不是站桩。
5. 隐藏人物后，projectile 仍能说明来源、方向、Travel、Contact、Impact。
6. 平A每次只有一枚真实伤害 projectile；旧人物 Pose 不得烘焙第二枚攻击。
7. 法相本体与投影不改变碰撞体、伤害范围和数值。
8. GIF/MP4 只有真实 Godot 运行录像可以作为运行验收；PIL/静态拼图不得再作为游戏效果证据。
