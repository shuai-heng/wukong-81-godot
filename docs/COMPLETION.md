# 像素版完工执行记录

负责人 2026-09-08 已要求直接实现并完成游戏，确认正式采用像素风。沿用 GitHub ead437c 的玩法目标，覆盖 c3639bf Godot 原型的已确认缺陷。本文件记录实现，不构成再次审批。

## 完工标准

1. 可直接启动、有标题/继续/新旅程、操作说明、设置、暂停、存档与结束画面。
2. 七英雄各有独立像素形象、移动/攻击/受伤/施法动画，以及普攻/Q/E/G/法相/终结与对应音效。
3. 真实命中停顿、清楚的预警/接触/余波；死亡仅结算一次；技能资源和冷却清楚。
4. 唐僧唯一初始人物，五行山解封预演、鹰愁涧/高老庄/流沙河收徒完整。
5. 人物外传解锁能力，入口提示来源，正确人物与能力改变后续地图或 Boss；保存人物与能力独立状态。
6. 按原著地点铺完整西行路线到取经、通天河补难、东土结局。八十一难采用故事事件与战斗段落编排，不用 81 个换名空场冒充内容。
7. 构筑、不同敌人、Boss 阶段与机制、游戏失败重试、自由重游、通关记录。
8. 实跑逻辑回归、实际渲染截图/交互与性能检查，交付像素游戏可启动包。

## 架构

- `scripts/content.gd`：人物、路线章节、外传、能力、地图主题、目标与 Boss 参数。
- `scripts/game.gd`：旅程、输入、战斗时钟、波次、目标与保存协调。
- `scripts/fighter.gd` / `scripts/foe.gd`：人物状态机、命中、专属技能和敌人 AI。
- `scripts/pixel_world.gd` / `scripts/battle_fx.gd`：像素地图、环境机制、攻击轨迹与反馈。
- `scripts/game_hud.gd`：HUD、菜单、路线、人物、升级选择。
- `scripts/sound_rack.gd`：音效分层、有限音频池、原创程序化音乐。
- `tools/build_pixel_art.py`：独立角色与敌人的像素帧生产；版本库中的正式 PNG。
- `scripts/journey_save.gd`：独立 v2 存档、原子写入、设置与损坏恢复。

## 实现与交付记录

2026-09-08：完成像素版旅程实现与 Windows 包。新入口为 `scenes/main.tscn -> scripts/game.gd`；旧原型脚本保留用于追溯，但不参与实际游戏和导出包。原始仓库与 E 盘联接保持不动。

- 35 套原创像素帧图（7 英雄、28 敌人），每套含 5 种动作、每动作 8 帧。悟空变化、真龙和七种法相另有状态外形。
- 22 个合成音效、4 首五声音阶循环配乐；普通非致死命中也出声，技能与重击有不同反馈。声音限频和池容量限制避免音效叠爆。
- 命中停顿由共同战斗时钟执行，敌人、位移、攻击队列和危险区一起停；动画接触帧延后结算。尸体重复命中不重复掉落。
- 36 处西行地点、81 段事件、10 个外传、独立人物/神通所有权、路线门禁、三阶段 Boss、实际收服交互与结局。
- 巡行妖潮、护送灵灯、风眼、火阵、迷雾、破幻、净化和水域。完整天宫战斗展示哪吒和杨戬，五行山展示棍击、破幻光束、分身与巨棒。
- 章内检查点恢复任务阶段、目标击杀、护送位移/气血、人物气血和 Boss 阶段；每 15 秒以及结算/返回标题/关窗保存。

正常通关测试通过输入移动、真实技能冷却和正常伤害推进目标，不注入秒杀伤害，不跳阶段。回归测试中的超大伤害仅用于验证 Boss 不会跳过阶段；压力测试的无敌仅用于稳定负载，均不是通关证据。通关 JSON 中 HP 是结算后的补血数值，不能作为“无伤通关”的依据。

真实 GPU/音频驱动运行与退出无报错。无界面沙箱的 Dummy 音频驱动退出会报告音频播放资源仍被引用，另有系统证书和编辑器 C 盘设置写入被沙箱拦截；这些保留在对应日志，未冒充无界面零警告。正式包不启动编辑器，默认关闭文件日志；可选启动脚本明确把日志放入旁边 `userdata`。

这是从开始到结局可走通的本地候选游戏。关卡以目标、环境、敌人和首领组合编排，部分地图布局与战斗机制复用；未实现配音、联机或逐场长篇过场动画。美术风格、音色和操作手感仍应以负责人实际游玩为准；自动通过不能代替人工最终接受。未发布 GitHub 稳定 Release，未触发 GitHub Actions。

Windows 包带本机 Godot 4.7.2 运行二进制和独立 PCK，故体积主要来自引擎。`release/licenses/GODOT-ENGINE-EXACT.txt` 直接从实际引擎的授权 API 导出许可和组件版权，另附官方 LICENSE/COPYRIGHT。`release/BUILD-MANIFEST.json` 记录精确源代码提交与文件 SHA-256。
